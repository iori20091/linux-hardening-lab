# Informações do Sistema

## Objetivo

Identificar o ambiente Linux utilizado durante o laboratório.

---

## Comandos utilizados

### Nome do sistema

```bash
hostname
```

### Distribuição

```bash
cat /etc/os-release
```

### Kernel

```bash
uname -r
```

### Informações completas

```bash
uname -a
```

---

## Resultado

Cole aqui apenas as informações importantes obtidas nos comandos.

Evite publicar:

- Nome real da máquina
- Nome do usuário
- Endereço IP
- Domínio da rede

---

## O que aprendi

A identificação do sistema operacional é uma das primeiras etapas de qualquer auditoria ou inventário de ativos. Essas informações ajudam a verificar versões, compatibilidade e possíveis atualizações de segurança.
